# Contributing

Thanks for helping. Short version:

1. **Test reports** from other consoles or firmware are the most valuable contribution right now - use the issue templates. Everything here was tested only on a PS5 Pro with firmware 12.40.
2. **Code changes:** mods are generated by the Python scripts in `tools/mods/`; change the generator, rebuild with `python3 tools/mods/build_cheats.py --all-profiles`, and never hand-edit the JSON. Read `docs/agents/30-code-cave-playbook.md` before writing a code cave (it lists the mistakes that crashed the game before).
3. **Humans and AI agents** are equally welcome; AI agents should start with [AGENTS.md](AGENTS.md).
4. Do not include game assets, memory dumps, other people's binaries or secrets. By contributing you agree that your contribution is licensed under GPL-3.0.
